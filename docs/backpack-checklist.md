# Перед тем как положить мак в рюкзак

1. **Мак включён и разблокирован** после последней перезагрузки (из-за FileVault после перезагрузки сервисы не стартуют, пока не введён пароль).
2. **Включите режим:** `blueberry on`, затем `blueberry status`. Должно быть: `disablesleep: ВКЛ`, `caffeinate: работает`, порт 8787 на `*`, порт 1234 на `127.0.0.1`, `watchdog: работает`.
3. **Заряд.** Лучше подключить зарядку или иметь больше 50%. Без зарядки ниже 15% watchdog сам остановит сервисы и вернёт обычный сон.
4. **Hotspot.** Включите точку доступа на телефоне, убедитесь, что мак подключился: в `blueberry status` в разделе «Сеть» появился IP из сети телефона. Если IP новый, откройте приложение; при необходимости `blueberry qr` в новой сети и повторное сканирование.
5. **Проверьте с телефона:** приложение показывает «Подключено», тестовое сообщение получает ответ.
6. **Не закрывайте рюкзак наглухо.** Оставьте доступ воздуху, не кладите мак вплотную к одежде и одеялу, не оставляйте на солнце.
7. **После поездки:** `blueberry off`, чтобы мак снова спал при закрытой крышке.
