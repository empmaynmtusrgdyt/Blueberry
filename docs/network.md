# Сеть: как телефон находит мак

Приложение пробует три способа по порядку: **данные из QR** → **автообнаружение Bonjour (NsdManager)** → **ручной ввод IP:порт и токена**.
Сканирование подсети не используется.

## Что делает мак
- Прокси слушает порт 8787 (`PROXY_PORT`). Когда `PROXY_HOST=0.0.0.0`, он сам анонсирует сервис `_blueberry._tcp` через `dns-sd -R`
  (имя `BONJOUR_NAME`, по умолчанию «Blueberry»). Пока прокси на localhost, анонса нет.
- `blueberry qr` печатает QR с JSON `{"v":1,"name","host","port","mdns","token"}`; `blueberry qr --png` сохраняет PNG в
  `~/.config/blueberry/state/` (права 600, вне git; после использования удалите). QR нужно показывать, когда мак уже в той сети,
  где вы будете работать (IP в QR берётся из текущего подключения).
- Проверка анонса с мака: `dns-sd -B _blueberry._tcp local.` (с прокси на 0.0.0.0).

## Стабильный IP мака в сети hotspot
Адрес в сети телефона выдаёт DHCP-сервер телефона. Заранее закрепить его на Android-hotspot обычно нельзя
(в стандартной прошивке нет резервирования адресов), но можно сделать его на практике постоянным:

1. **Фиксированный MAC на маке.** Системные настройки → Wi-Fi → «Подробнее» рядом с сетью hotspot →
   «Private Wi-Fi address» → **Fixed** (не «Rotating»). DHCP привязывает аренду к MAC: с постоянным MAC телефон
   чаще всего выдаёт тот же IP.
2. **Не менять режим hotspot** (диапазон 2.4/5 ГГц и т. п.) между сеансами, чтобы подсеть не менялась.
3. **Подключать мак к hotspot первым**, до других устройств: адреса часто выдаются по порядку.
4. Если телефон всё равно выдаёт другой адрес, это нормально для Android: приложение не должно зависеть от IP.

## Если IP меняется при каждом подключении
- Работает автообнаружение Bonjour (имя сервиса не зависит от IP). На части телефонов mDNS в режиме hotspot ненадёжен,
  поэтому оно не единственный способ.
- В QR есть поле `mdns` (`<LocalHostName>.local`), приложение может использовать его как запасное имя.
- Если ничего не нашлось, на маке выполните `blueberry qr` в новой сети и отсканируйте код снова:
  приложение обновит сохранённый адрес (токен остаётся прежним).
- Крайний случай: ручной ввод. IP мака смотрите командой `blueberry status` (строка «en0») или `ipconfig getifaddr en0`.

## Проверено на практике
Сквозной тест без интернета (телефон раздаёт hotspot с выключенным мобильным интернетом, мак с закрытой крышкой):
мак получил адрес `192.168.176.192`, а в приложении был сохранён старый `192.168.0.100`. Приложение само нашло мак
через Bonjour (NsdManager), повторного сканирования QR не потребовалось. Чат работал потоково при закрытой крышке.
Это проверено на одной паре устройств (мак и TECNO SPARK Go 1); на других телефонах mDNS в режиме hotspot может не работать,
тогда используйте `blueberry qr` или ручной ввод.
