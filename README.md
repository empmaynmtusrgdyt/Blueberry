# Blueberry

**Чат с локальной нейросетью Gemma, которая работает на вашем MacBook, а общаетесь вы с ней с Android-телефона. Интернет не нужен.**

Модель крутится на маке (через LM Studio). Телефон раздаёт точку доступа (hotspot), мак подключается к ней сам и отвечает
из рюкзака с закрытой крышкой. В приложении Blueberry вы просто пишете сообщения и получаете ответы по мере их генерации.

* Всё работает внутри вашей локальной сети, данные никуда не уходят.
* Мак не засыпает при закрытой крышке и сам выключает сервис при перегреве или низком заряде.
* Доступ только по секретному токену, который отдаётся телефону через QR-код.

## Что понадобится

**На маке**
* MacBook на Apple Silicon (проверялось на M4 / 16 ГБ), проверялось на macOS 26.
* [LM Studio](https://lmstudio.ai) установлена в `/Applications`, запущена хотя бы один раз, команда `lms` доступна (лежит в `~/.lmstudio/bin/lms`).
* В LM Studio скачана модель **Gemma 4 E4B** (`google/gemma-4-e4b`, около 7 ГБ). Проверить: `~/.lmstudio/bin/lms ls`.
  Другая модель тоже подойдёт: укажите её в `MODEL_KEY` (см. [Настройка](#настройка)).
* Python 3 и git (на маке обычно уже есть). Свободно около 10 ГБ на диске.

**На телефоне**
* Android 8.0 или новее.
* Для сканирования QR нужны Google Play Services (при первом запуске сканеру может понадобиться интернет). Без них адрес и токен вводятся вручную.

## Быстрый старт

Команды выполняются в приложении **Терминал** на маке.

1. **Скачайте проект:**
   ```bash
   git clone https://github.com/empmaynmtusrgdyt/Blueberry.git
   cd Blueberry
   ```
2. **Установите серверную часть** (без пароля, ставит три фоновые службы и создаёт токен):
   ```bash
   scripts/install-all.sh
   ```
3. **Разрешите включать режим закрытой крышки без пароля.** Команда спросит пароль мака, поэтому запускайте её в обычном окне Терминала (в оболочках без ввода пароля, например внутри редакторов, она не сработает). Посмотреть заранее, что она сделает: `scripts/install-sudoers.sh show`.
   ```bash
   scripts/install-sudoers.sh install
   ```
4. **Добавьте команду `blueberry` в PATH** (один раз), затем откройте новое окно Терминала:
   ```bash
   echo 'export PATH="$HOME/.config/blueberry/bin:$PATH"' >> ~/.zshrc
   ```
5. **Установите приложение на телефон**, см. [Установка приложения](#установка-приложения-на-телефон).
6. **Запустите сервер** и подождите 10–20 секунд, пока загрузится модель:
   ```bash
   blueberry on
   ```
7. **Подключите телефон:** выполните `blueberry qr`, в приложении нажмите «Сканировать QR» и наведите камеру на код. Затем «Проверить соединение» → «Сохранить» → «+» (новый чат).

Готово. Перед поездкой пройдитесь по [памятке для рюкзака](docs/backpack-checklist.md). Закончили: `blueberry stop`.

## Команды

Команда `blueberry` доступна после шага 4. Без него вызывайте `~/.config/blueberry/bin/blueberry`.

| Команда | Что делает |
|---|---|
| `blueberry on` | запуск: поднимает сервисы и модель, включает режим закрытой крышки (мак не засыпает) |
| `blueberry stop` | полная остановка: возвращает обычный сон, останавливает сервер, модель и фоновый процесс LM Studio. Обратно: `blueberry on` |
| `blueberry off` | только вернуть обычный сон, сервер остаётся работать |
| `blueberry status` | что сейчас включено: режим, питание, батарея, нагрев, IP, порты, сервисы, срабатывания сторожа |
| `blueberry qr` | QR для подключения телефона (`--png` показать картинкой; удалите её после использования) |

После долгого простоя (20 минут без запросов) модель выгружается из памяти, а при первом сообщении загружается снова:
это **холодный старт, около 10–20 секунд**, приложение показывает «Модель загружается…».
Если сторож остановил сервисы из-за перегрева или заряда, `blueberry on` снимает аварийный режим и всё запускает заново.

## Установка приложения на телефон

Готовый файл лежит в репозитории: [`dist/Blueberry-debug.apk`](dist/Blueberry-debug.apk) (16 МБ).

1. Передайте файл на телефон: откройте его на GitHub и скачайте, либо отправьте себе в Telegram («Избранное»), Google Drive или почтой.
2. Откройте скачанный файл на телефоне. Android попросит **разрешить установку из этого источника** (для браузера, Telegram и т. п.): включите разрешение и вернитесь к установке.
3. Если Play Protect предупредит о непроверенном приложении, нажмите «Всё равно установить»: это отладочная сборка, подписанная локальным ключом.
4. Откройте Blueberry: первым покажется экран «Подключение». Продолжайте с шага 7 быстрого старта.

Приложение можно пересобрать самому: `cd android && ./gradlew assembleDebug`, результат лежит в `app/build/outputs/apk/debug/app-debug.apk`
(нужны JDK 21 и Android SDK; файл `android/local.properties` с `sdk.dir=...` создаётся вручную).
Установка поверх старой версии сохраняет чаты и настройки.

## Подключение телефона и hotspot

Мак и телефон должны быть в одной сети: либо в обычной Wi-Fi, либо мак подключён к hotspot телефона (основной сценарий).

1. **Один раз подключите мак к hotspot вручную** и включите «Автоматическое подключение» (Системные настройки → Wi-Fi → Подробнее рядом с сетью).
   Пароль сети в проекте нигде не хранится.
2. **Для стабильного адреса** включите для этой сети «Private Wi-Fi address: Fixed».
3. Телефон показывает сеть без интернета, это нормально: Blueberry работает только по локальной сети.

Как приложение ищет мак (по порядку): **1)** сохранённые данные из QR → **2)** автообнаружение Bonjour, если адрес сменился → **3)** ручной ввод IP, порта и токена
(токен лежит в `~/.config/blueberry/token`). Подробности: [docs/network.md](docs/network.md).

## Настройка

Файл `~/.config/blueberry/config.env` (шаблон: `config.example.env`). После правки перезапустите нужную службу:
`launchctl kickstart -k gui/$(id -u)/com.blueberry.proxy` (то же для `watchdog`; для `lmstudio` проще `blueberry stop` и `blueberry on`).

| Параметр | По умолчанию | Смысл |
|---|---|---|
| `PROXY_HOST` / `PROXY_PORT` | `0.0.0.0` / `8787` | адрес прокси (`127.0.0.1` оставит доступ только на самом маке) |
| `MODEL_KEY`, `MODEL_IDENTIFIER`, `MODEL_CONTEXT` | `google/gemma-4-e4b`, `gemma`, `8192` | какая модель, под каким именем, размер контекста |
| `PROXY_MAX_BODY_BYTES`, `PROXY_MAX_CONCURRENT` | 262144, 2 | максимальный размер запроса и число одновременных запросов |
| `WD_BATTERY_MIN_PERCENT` | 15 | ниже этого заряда без зарядки сторож всё остановит |
| `WD_THERMAL_LEVEL`, `WD_CPU_SPEED_LIMIT_MIN`, `WD_THERMAL_SUSTAIN_SECONDS` | 2, 70, 180 | признаки перегрева и сколько секунд они должны держаться |
| `WD_IDLE_MINUTES` | 20 | через столько минут без запросов модель выгружается |
| `BONJOUR_NAME` | `Blueberry` | имя сервиса для автопоиска |

Размер контекста в приложении (Подключение → «Новые чаты») должен совпадать с `MODEL_CONTEXT`: по нему обрезается история.

## Как это устроено

```
┌────────────── Android ───────────────┐          ┌──────────────────── MacBook ───────────────────────┐
│ Приложение Blueberry                 │          │                                                    │
│  • чат, история (Room)               │  Wi-Fi   │  com.blueberry.proxy   :8787  (0.0.0.0)            │
│  • токен в Keystore                  │ ───────▶ │   • Bearer-токен, 401 без него                     │
│  • QR / Bonjour / ручной ввод        │  HTTP    │   • SSE-стрим, отмена при обрыве клиента           │
└──────────────────────────────────────┘ (LAN)    │   • загрузка модели после idle (холодный старт)    │
                                                  │            │ 127.0.0.1                             │
                                                  │            ▼                                       │
                                                  │  com.blueberry.lmstudio  :1234  (только localhost) │
                                                  │   LM Studio server + google/gemma-4-e4b            │
                                                  │                                                    │
                                                  │  com.blueberry.watchdog  (заряд, перегрев, idle)   │
                                                  │  blueberry on|off|stop|status|qr (сон, caffeinate) │
                                                  └────────────────────────────────────────────────────┘
```

* Наружу смотрит только прокси (порт 8787). LM Studio слушает 127.0.0.1; при желании порт 1234 дополнительно закрывается правилом pf (`scripts/blueberry-firewall show`).
* Разрешены три пути: `GET /health` (без токена), `GET /v1/models` и `POST /v1/chat/completions` (с токеном).
* Прокси анонсирует Bonjour-сервис `_blueberry._tcp`, пока слушает не только на localhost.

### Словарь

| Термин | Что это |
|---|---|
| **hotspot** | точка доступа: телефон раздаёт Wi-Fi |
| **токен** | длинный секретный пароль доступа; лежит в `~/.config/blueberry/token`, телефону передаётся через QR |
| **LaunchAgent** | фоновая служба macOS, которая стартует при входе в систему и перезапускается при падении (у проекта их три) |
| **сторож (watchdog)** | служба, которая раз в 30 секунд проверяет заряд, нагрев и простой и при проблемах выключает сервер; проверяет заряд и нагрев только пока сервер или режим закрытой крышки включены |
| **sudoers / helper** | разрешение macOS запускать одну узкую команду управления сном без пароля; без неё `blueberry on/off` каждый раз просил бы пароль |
| **pf** | встроенный сетевой экран macOS; необязательно используется, чтобы закрыть порт 1234 |
| **SSE** | способ получать ответ модели по кусочкам, поэтому текст «печатается» по ходу генерации |
| **холодный старт** | загрузка модели в память после простоя, около 10–20 секунд |
| **Bonjour (mDNS)** | автоматический поиск устройств в локальной сети без ввода IP |
| **localhost / 127.0.0.1** | «только этот компьютер»; снаружи недоступно |

## Диагностика

Сначала выполните `blueberry status`: он покажет режим, сеть, порты, сервисы и последние срабатывания сторожа.

| Симптом | Что проверить |
|---|---|
| Приложение пишет «Неверный токен» (401) | токен в приложении не совпадает с `~/.config/blueberry/token`: выполните `blueberry qr` и отсканируйте код заново |
| «Сервер недоступен» | `blueberry status`: порт 8787 должен быть на `*`; телефон и мак в одной сети? Выполнен ли `blueberry on`? |
| Приложение не находит мак само | сменился IP, а Bonjour на телефоне не сработал: `blueberry qr` в новой сети и сканирование, либо ручной ввод |
| Долго нет ответа после простоя | идёт холодный старт, подождите до 30 секунд |
| Ошибка «Сервер занят» (429) | заняты оба слота запросов, повторите через несколько секунд |
| Мак засыпает при закрытой крышке | `blueberry status`: должно быть `disablesleep: ВКЛ`. Режим включается только командой `blueberry on` |
| Мак внезапно «выключил» сервер | `cat ~/.config/blueberry/state/alerts.log`: сторож остановил сервис из-за заряда или перегрева. Верните командой `blueberry on` |
| После перезагрузки мака ничего не работает | введите пароль FileVault на экране входа, затем `blueberry on` (см. ограничения) |

Полезные команды:

```bash
tail -f ~/Library/Logs/Blueberry/proxy.log                     # запросы (метод, путь, статус, время; без содержимого)
tail -f ~/Library/Logs/Blueberry/watchdog.log                  # срабатывания сторожа
tail -f ~/Library/Logs/Blueberry/lmstudio.log                  # запуск сервера и модели
launchctl print gui/$(id -u)/com.blueberry.proxy | grep state  # состояние службы (то же для lmstudio, watchdog)
lsof -nP -iTCP:8787 -iTCP:1234 -sTCP:LISTEN                    # кто слушает порты (1234 только 127.0.0.1)
curl -s http://127.0.0.1:8787/health                           # {"status":"ok","model":"loaded|unloaded|loading"}
pmset -g | grep -E "SleepDisabled|sleep"                       # режим сна
pmset -g assertions                                            # что мешает сну
pmset -g therm                                                 # тепловое состояние
dns-sd -B _blueberry._tcp local.                               # виден ли Bonjour-сервис
~/.lmstudio/bin/lms ps                                         # загружена ли модель
```

## Известные ограничения

* **FileVault.** После перезагрузки или полной разрядки мак ждёт ввода пароля FileVault до загрузки системы; без него не стартует ни сеть, ни службы. Автологин при включённом FileVault недоступен. Сервер рассчитан на мак, уже включённый и разблокированный перед тем, как его положили в рюкзак.
* **Нагрев в рюкзаке.** Закрытый наглухо рюкзак плохо охлаждает мак. Сторож выключит сервер при устойчивом перегреве, но лучше оставить доступ воздуху.
* **Без шифрования (TLS).** Трафик между телефоном и маком идёт по HTTP внутри локальной сети, защищён только токеном. Приложение принимает только локальные адреса (10.x, 172.16–31.x, 192.168.x, 169.254.x, `*.local`).
* **Имя Wi-Fi сети** macOS скрывает от процессов без права на геолокацию, поэтому `blueberry status` показывает IP и шлюз, а не название сети.
* **Приложение в фоне.** Если Android завершит процесс приложения, идущая генерация прервётся (история сохраняется, незавершённый ответ нет).
* **Bonjour** на hotspot Android работает не на всех телефонах (на TECNO SPARK Go 1 проверено, работает); поэтому есть QR и ручной ввод.
* **Один пользователь, один сервер.** Параллельно обслуживаются максимум 2 запроса.

## Полный откат

В обычном окне Терминала:

```bash
scripts/uninstall-all.sh --dry-run    # посмотреть план
scripts/uninstall-all.sh              # откатить всё, сохранив токен и конфиг
scripts/uninstall-all.sh --purge      # дополнительно удалить ~/.config/blueberry и логи
```

Откат возвращает настройки питания, останавливает `caffeinate`, снимает правило pf (если применялось), удаляет запись sudoers и helper,
останавливает и удаляет службы `com.blueberry.*`, выгружает модель и останавливает сервер LM Studio.
Части можно откатывать по одной: `scripts/install-sudoers.sh uninstall`, `scripts/blueberry-firewall remove`,
`scripts/install-proxy.sh uninstall` (аналогично `install-lmstudio.sh`, `install-watchdog.sh`).

## Структура репозитория

| Путь | Что там |
|---|---|
| `server/proxy.py` | прокси с авторизацией, стримингом и Bonjour |
| `server/watchdog.py` | сторож: перегрев, разрядка, простой |
| `scripts/blueberry` | переключатель `on` / `off` / `stop` / `status` / `qr` |
| `scripts/install-*.sh`, `install-all.sh` | установка служб и системных частей |
| `scripts/uninstall-all.sh` | полный откат |
| `scripts/blueberry-pmset-helper`, `install-sudoers.sh` | привилегированный helper и узкая запись sudoers |
| `scripts/blueberry-firewall`, `firewall/` | необязательное правило pf для порта 1234 |
| `launchd/` | шаблоны LaunchAgent |
| `android/` | исходники приложения (`com.blueberry.app`) |
| `dist/Blueberry-debug.apk` | готовое приложение |
| `docs/` | сеть и обнаружение, памятка для рюкзака |
| `config.example.env` | шаблон конфигурации |

Системные пути: конфигурация и токен `~/.config/blueberry/` (`config.env`, `token`, `state/`, `bin/`, `venv/`),
логи `~/Library/Logs/Blueberry/`, службы в `~/Library/LaunchAgents/`.
